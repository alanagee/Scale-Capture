Print a Target Marker

A precise black square, sized to print across one or more Letter sheets that you trim and tape together.

Marker size

in
Matches the target size setting in the Scale Capture app — set it the same in both places. Squares up to about 7×7″ print on a single sheet; larger ones tile across multiple sheets.

How to build it

  1. Print this page at 100% / Actual Size — make sure "Fit to page" or "Scale to fit" is turned off.
  2. Check the small ruled calibration line on the first sheet with an actual ruler. It should measure exactly 3.00″. If it doesn't, your printer is scaling the page — adjust the print scale by that ratio and reprint, or account for the difference when you set the target size in the app.
  3. Trim each sheet along the dashed line, and line up the small + marks at matching edges when you tape sheets together.
  4. Mount the assembled square on stiff card/board so it stays flat — it needs to lie in the same plane as whatever you're photographing.
